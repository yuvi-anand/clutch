# Changelog

## 0.2.0 (beta) — 2026-10

First release for Northeastern testers.

- **One-command install and guided setup.** `install.sh` downloads Clutch. `setup.sh` installs Node.js and Claude Code if needed, signs you in with your Northeastern Claude subscription, connects Canvas and builds the app. `start.sh` opens it, `update.sh` updates it, and there's an optional Desktop icon.
- **Runs on your Claude subscription** through the local Claude Code app. No API key is needed.
- **Margin notes:** highlight text in a guide and ask about it. Answers are short sticky notes beside the passage, and you can delete them. Formulas highlight as one rounded mark.
- **Your week:** add trips, clubs, internships and interview prep, and the catch-up plan works around them.
- **Classes off Canvas:** add a class by hand, with a website, uploads or pasted notes. Dates on course websites show up on the dashboard.
